## Known gotchas

- launchd does NOT source ~/.zshrc. To give a launchd service an env var, put it in the plist EnvironmentVariables, OR restart the service from an interactive shell that sourced ~/.zshrc.
- Stale process holds port → new start exits 1. Always `lsof -ti:<port> | xargs kill -9` before restarting.
- zsh interactive mode doesn't enable inline `#` comments — don't put `#` after a pipe.
- GHL token must not be committed to the repo (.gitignore covers .env).
